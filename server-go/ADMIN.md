# Админка расходов ИИ

1. Задайте отдельный длинный случайный `ADMIN_TOKEN` в окружении сервера / `.env`.
   Не используйте токен приложения и не включайте его в APK.
2. Проверьте цены `DEEPSEEK_PRICE_INPUT_MISS`, `DEEPSEEK_PRICE_INPUT_HIT`,
   `DEEPSEEK_PRICE_OUTPUT` (USD за миллион токенов), `TRANSCRIBE_PRICE_PER_MIN`
   и `PRICE_VERSION`.
3. Пересоберите и перезапустите Go-сервер. Откройте `https://ваш-сервер/admin`
   и введите `ADMIN_TOKEN`. Отдельная сборка фронтенда не нужна: файлы встроены в Go-бинарник.

Панель показывает **всех зарегистрированных клиентов**, включая аккаунты без расходов,
дату регистрации, остаток диагностик и срок подписки. Дополнительно отображаются
незарегистрированные владельцы из журнала (например, `anonymous`). Суммы в USD,
токены с разделением кэша, минуты STT. Клик по ID клиента открывает детализацию
по дням, операциям и сессиям. Даты включительные, в UTC. По умолчанию — 30 дней.
Кнопка «Обновить» запрашивает новые данные; автоматического обновления нет.

Токен передаётся при входе в `X-Admin-Token` и не сохраняется в браузере.
Вход запоминается на 30 дней через подписанную Secure/HttpOnly/SameSite=Strict
cookie. Кнопка «Выйти» удаляет её. Смена ADMIN_TOKEN отменяет все выданные сессии.
Для входа через браузер обязателен HTTPS.
API админки не требует `APP_TOKEN`, но всегда проверяет `ADMIN_TOKEN`.
Без настроенного `ADMIN_TOKEN` панель отключена. Данные API не кэшируются.

Это учёт себестоимости по настроенным ценам, не списание денег с клиента.
Журнал — `DATA_DIR/llm_usage.jsonl`; включите его в резервное копирование.
Исторические расходы не пересчитываются при смене тарифов. Старые сессии
без привязки к клиенту отображаются как `anonymous`.
