# AlfaDiag — отчёт по сессии

**Дата:** 25 октября 2026  
**Ветка:** `diagnostic-sync`  
**Репозиторий:** [031168-sudo/Diagnostic-tool](https://github.com/031168-sudo/Diagnostic-tool)  
**Приложение:** AlfaDiag / `ru.alfanomy.diagnostictool`, versionCode 4, versionName 1.3

---

## 1. Кратко

За сессию приложение заметно переработано: современный чат с ИИ, сохранение диалогов,
резервное копирование, управление автомобилями, две приборные панели, светлая/тёмная
темы с ручным переключателем и автомобильные иконки.

Сервер получил человекочитаемый транскрипт диалога и ограничение темы чата
автомобильной диагностикой.

## 2. Android-приложение

### 2.1. Чат с ИИ

- Убран микрофон и голосовой ввод из чата.
- Поле ввода стало «композером»:
  - одна строка, растёт до 5 строк, дальше внутренняя прокрутка;
  - круглая кнопка отправки со стрелкой;
  - «Сохранить PDF» и «Назад» — компактные кнопки внутри композера.
- Корректная работа с клавиатурой: `imePadding` + `consumeWindowInsets`,
  без «прыжков» и перекрытия полем ввода.
- Сохранение диалога:
  - сервер хранит `transcript` (вопросы ИИ, ответы владельца, заключение, чат после);
  - приложение показывает транскрипт из статуса сессии;
  - локальный кэш транскрипта в `DiagnosticRecordStore` — диалог виден даже без сервера;
  - при сохранении PDF итоговое заключение обновляется в переписке.

### 2.2. Отправка в ИИ

- Вместо тоста — модальное окно передачи с полосой прогресса и процентами.
- Прогресс реальный: считаются отправленные байты multipart-запроса.
- Пока идёт передача, UI заблокирован.
- Ошибка → «Повторить» / «Закрыть»; успех → переход в чат диагностики.

### 2.3. Автомобили

- Диалог «Сменить»:
  - карандаш (редактировать) и корзина (удалить) справа от каждой машины;
  - внизу «+ Добавить» и «Закрыть».
- Удаление автомобиля:
  - «страшное» подтверждение с предупреждением и путём к PDF;
  - удаляются диагностики, `.adp`-файлы сессий, PDF, сервисная книжка и сама машина;
  - если машин не осталось — предлагается добавить первую.

### 2.4. Резервное копирование

- В «Аккаунте»:
  - «Сохранить копию сейчас»;
  - «Восстановить из копии»;
  - информация о последней копии: дата/время, имя файла, путь.
- Формат — ZIP:
  - `backup.json` (машины, диагностики, сервисная книжка, настройки, транскрипты);
  - `sessions/*.adp`;
  - `conclusions/*.pdf`.
- Папка: `Download/Alfa Diagnostic/backups`.
- Авто-бэкап: при запуске и далее каждые 10 минут, если данные менялись.
- Хранятся 3 последние копии.
- Восстановление доступно и с первого экрана «Добавить автомобиль».
- Аккаунт (токен) в архив не кладётся — для переноса используется код переноса.

### 2.5. Приборная панель (первый экран)

- Круглые приборы в стиле референса:
  - внешнее кольцо, деления, крупные цифры по кругу;
  - большая цифра в центре, единица под ней;
  - стрелка — короткая неоновая по внешнему краю (не перечёркивает цифры).
- Спидометр и тахометр; ОЖ; напряжение; температура за бортом.
- Убраны по просьбе: «Расход», проценты топлива, подписи «Скорость»/«Обороты»,
  заголовок «ПРИБОРНАЯ ПАНЕЛЬ».
- Нижние карточки: иконка + значение + единица; позиции зафиксированы,
  чтобы цифры не двигали layout.
- Поездка: пробег, время, средняя скорость, сброс; дата и время.
- Переключение вида: портрет/ландшафт вручную, выбор запоминается.
  Первый запуск — портрет.
- Экран не гаснет, пока открыта приборка (и во время записи).
- Расширенные PID опрашиваются только при открытом профэкране,
  чтобы не тормозить основные приборы.

### 2.6. Профессиональный экран

- Открывается кнопкой «Диагностика →».
- Параметры:
  - STFT/LTFT B1/B2, режим смеси;
  - MAF, MAP, наддув, дроссель, нагрузка;
  - угол зажигания, крутящий момент;
  - лямбда B1S1/B1S2, температура катализатора;
  - температура масла, ОЖ, напряжение;
  - давление в топливной рампе;
  - EGR и ошибка EGR;
  - впуск, за бортом, атмосферное давление;
  - CHECK ENGINE: статус, количество и список кодов.
- Сетка: 2 колонки в портрете, 3 в ландшафте.

### 2.7. Темы

- Material 3 светлая и тёмная схемы.
- Переключатель в «Аккаунте»: **Системная / Светлая / Тёмная** (по умолчанию системная).
- Настройка сохраняется и применяется сразу.
- Приборная панель имеет собственную светлую и тёмную палитру.
- Профэкран использует цвета темы.
- Строка статуса Android подстраивает цвет иконок под тему.

### 2.8. Иконки

- Автомобильный стиль:
  - **ОЖ** — термометр с делениями и волнами;
  - **аккумулятор** — широкая батарея с «−» и «+»;
  - **погода** — солнце + туча + дождь.
- Размер увеличен (40 dp в карточках, 34 dp в центральной панели),
  цвет — как текст темы (чёрный/белый), значения остаются цветными.

## 3. Сервер (Go)

- `SessionState.Transcript` и `PublicState.Transcript` — человекочитаемый диалог.
- Транскрипт пишется:
  - при первичном анализе;
  - при ответе на уточняющий вопрос;
  - в чате после заключения;
  - при финализации PDF (обновляется итоговое заключение).
- Промпт чата ограничен автомобильной темой:
  - разрешены результаты диагностики, конкретная машина и её типовые проблемы,
    общие вопросы эксплуатации/ремонта;
  - на посторонние вопросы — короткий отказ и возврат к машине;
  - в чат передаются данные автомобиля (марка, модель, год, двигатель и т.д.).
- В серверный коммит также вошли админ-панель и учёт расходов
  (ADMIN_TOKEN, журнал usage, страница `/admin`).

## 4. Коммиты сессии

| Коммит | Содержание |
| --- | --- |
| `86b6200` | `server-go`: админ-панель, учёт расходов, транскрипт, ограничение темы чата |
| `0c88249` | `app`: композер чата, бэкапы, управление авто, приборная панель |
| текущий | светлая/тёмная темы, переключатель, палитры приборки, иконки, отчёт |

## 5. Ограничения и что осталось

- **Ключ DeepSeek:** на момент сессии ключ `sk-...8f35` отозван, сервер отвечает `401`.
  Анализ и чат не работают до замены ключа в `server-go/.env`.
- **Старые сессии:** созданные до появления `transcript`, показывают только текущий
  вопрос/заключение — полного диалога у них нет.
- **Серверные копии:** удаление автомобиля в приложении чистит телефон,
  но не серверный том (отдельного endpoint удаления нет).
- **Топливо/расход:** по просьбе убраны с приборок и из опроса PID.
- **Пробег по OBD:** не читается — стандартный OBD-II его почти не отдаёт.
- **Аккаунт в бэкапе:** токен не включается; перенос — кодом переноса.
- **Версия:** versionCode/versionName не поднимались в этой сессии (4 / 1.3).

## 6. Сборка и проверка

**Android:**

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
export ANDROID_SDK_ROOT="$HOME/Android/Sdk"
/home/gmpony/opt/gradle/gradle-8.11.1/bin/gradle assembleDebug --no-daemon
```

APK: `app/build/outputs/apk/debug/app-debug.apk`  
Публикация: `~/public/apk/app-debug.apk`

**Сервер:**

```bash
cd server-go
docker compose up -d --build
curl -s http://127.0.0.1:44096/health
```

**Тесты сервера:**

```bash
cd server-go
docker run --rm -v "$PWD":/src -w /src golang:1.27-alpine go test ./...
```
